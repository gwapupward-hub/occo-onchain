# OCCO v1 Product Requirements Document

## Product
OCCO — OnChain Credit Organization

## Mission
OCCO provides standardized, explainable, and verifiable credit scores for on-chain wallets.

## Target Chain
- Solana (v1 only)

## Core Outputs
- OCCO Score (300–850)
- OCCO Risk Tier (A–E)
- OCCO Credit Report
- OCCO Attestation (optional)

## User Types
1. Public users (wallet lookup)
2. Wallet owners (opt-in profile)
3. Protocols (API consumers)

## v1 Scope
- Public wallet credit lookup
- Deterministic off-chain scoring
- Opt-in full credit reports
- Optional on-chain attestations

## Non-Goals
- Cross-chain support
- Identity binding
- Tokens or governance
- Social reputation features

## Success Metrics
- <500ms score retrieval
- Deterministic, repeatable scoring
- Explainable factors for every score
- API-first adoption
